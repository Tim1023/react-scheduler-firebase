## 房屋概况

| 项目 | 详情 |
|------|------|
| 卧室 | 5 间（4 间双人房 + 1 间单人房/书房） |
| 浴室 | 2.5 间 |
| 起居空间 | 4+（主客厅、正式餐厅、影音/游戏室、楼下灵活大书房/卧室） |
| 户外 | 地中海风格泳池 + 独立泳池房 |
| 风格 | Art Deco，拱门元素，需考虑与之协调的家具线条与色调 |

**通用风格建议**：Art Deco 适合几何线条、对称布局、暖色木质 + 黄铜/金色点缀、
丝绒或皮革软装；避免过于现代极简，以呼应房屋的拱门和年代感。
